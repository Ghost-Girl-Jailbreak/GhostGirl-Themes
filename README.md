## 🌌 About

</div>

**GhostGirl Themes** lets you browse, preview, and apply custom themes to your Xbox 360 dashboard — all from your console.

Part of the [Project Ghost Girl](https://github.com/Ghost-Girl-Jailbreak/Project-Ghost-Girl) app store.

<div align="center">

| Feature | Description |
|:---|:---|
| 🎨 **Theme Browser** | Browse all available themes in one place |
| 👁️ **Preview** | See how a theme looks before applying |
| ⚡ **One-Click Apply** | Apply any theme instantly |
| 🔄 **Revert** | Restore the default theme anytime |
| 🚫 **No Telemetry** | Runs entirely on-console |

</div>

> ⚠️ **Requires a jailbroken Xbox 360** running ABadUpdate or ABadAvatar.

## 📥 Install

</div>

### ⭐ Recommended — Install via Project Ghost Girl App Store

The easiest way to install **GhostGirl Themes** is through the
**Project Ghost Girl app store** on your console.

- ✅ Automatic downloads
- ✅ One-click install
- ✅ Always get the latest version
- ✅ No manual file management

Just open the store on your jailbroken console, find **Themes**
in the app list, and hit install. Done.

### 🛠️ Manual Download (Not Recommended)

If you can't use the app store, you can install manually:

1. Download `GhostThemes.xex` from the [Releases](../../releases) page.
2. Place it in `Hdd:\Apps\Themes\` on your console.
3. Launch it from your dashboard.

> ⚠️ **We recommend using the app store instead.** Manual installs
> mean you have to check for updates yourself.

## 🚀 Features

</div>

### Theme Browser

- Lists all available themes in a scrollable grid
- Shows a thumbnail preview of each
- Sorted by category (Dark, Light, Minimal, Colorful)

### Preview Mode

- Preview any theme before applying
- Takes over the screen temporarily
- Press **B** to exit preview at any time

### Apply / Revert

- **Apply** replaces the current dashboard theme
- **Revert** restores the default theme
- Original theme is backed up automatically before applying

### Safety

- If something goes wrong, a **safe mode** boots with the default theme
- Backup files are never deleted automatically

## 🎨 Themes

</div>

Themes are distributed as **release assets** on the
[Releases page](../../releases), not stored in this repo.

Each theme is a `.zip` pack you can download and install directly,
or install automatically through the Project Ghost Girl app store.

### Built-In Themes

| Theme | Style | Status |
|:---|:---|:---:|
| **Ghost Default** | Galaxy purple | 🚧 Planned |
| **Deep Space** | Dark | 🚧 Planned |
| **Neon Nights** | Colorful | 🚧 Planned |
| **Minimal Mono** | Minimal | 🚧 Planned |

### Theme Format

Each theme pack contains:

```
ThemeName.zip
└── ThemeName/
    ├── theme.ini        ← metadata
    ├── preview.png      ← thumbnail
    └── (theme files)
```

Full format spec → [themes/README.md](themes/README.md)

### Adding Your Own

Theme submissions aren't open yet, but the plan is:

1. Build a theme folder following the format
2. Submit via a GitHub issue on the main repo
3. If approved, it gets bundled into the next release

More details in [themes/README.md](themes/README.md).

## ⚠️ Safety

</div>

- Applying a theme replaces your current dashboard files.
- The app **backs up** the current theme before applying a new one.
- If a theme is broken, use **Y** to revert to default.
- Use at your own risk — see the [Project Ghost Girl Disclaimer](https://github.com/Ghost-Girl-Jailbreak/Project-Ghost-Girl/blob/main/DISCLAIMER.md).
